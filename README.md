# MindForge — Visual Mind Map Editor

Create beautiful mind maps and knowledge graphs right in your browser. No signup, no install — just open and start mapping your ideas.

**Live Demo:** [mindforge-map.surge.sh](https://mindforge-map.surge.sh/)

## Features

- **Quick node creation** — Double-click canvas to add, double-click node to edit
- **Drag & drop** — Move nodes freely with mouse or touch
- **Smart linking** — Link mode with visual feedback
- **Force-directed auto-layout** — One-click beautiful arrangement
- **7 color themes** — Color-coded nodes for visual clarity
- **Zoom & pan** — Scroll to zoom, drag to pan, pinch on mobile
- **Context menu** — Right-click for edit, color change, delete
- **PNG export** — Download your mind map as an image
- **Bezier curve links** — Smooth curved connections
- **Touch support** — Works on tablets and phones

## Tech

- Canvas 2D API for rendering
- Force-directed graph layout algorithm
- Bezier curves for link rendering
- View transform matrix (pan + zoom)
- Single HTML file, zero dependencies
